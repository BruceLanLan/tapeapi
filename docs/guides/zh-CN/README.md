# 指南

面向任务的指南。每篇都从一个干净的仓库检出开始，到一个能跑起来的结果结束。网页版（可搜索）在 [tapeapi.fun/docs](https://tapeapi.fun/docs/)。

| 指南 | 适用对象 | 你将会 |
|---|---|---|
| [简介](introduction.md) | 初次接触 TapeAPI 的所有人 | 了解它是什么、如何工作、链上地址，以及接下来该读哪篇。 |
| [公共 API](public-api.md) | 现在就想要链上数据或中继的任何人 | 调用免费的公共服务（8 个有签名的 BNB Chain 与 TapeOut 读取方法，其中 7 个锚定区块），使用免费的公共中继。 |
| [调用服务](consume.md) | 应用与后端开发者 | 在链上解析服务、调用它、验证回答、为调用付费、要求多个提供者之间达成一致。 |
| [运行服务](provide.md) | API 提供者 | 把函数或现有的 REST API 变成签名方法，从手机或服务器上线，续期，运维。 |
| [接入 AI 服务](ai-providers.md) | AI 中转站（new-api）、网关、聚合商与自建模型的团队 | 在你的 AI 接口前面放一个签名旁路：链上身份、钉在链上的价目表、每次调用一份签名的用量回执，用户不用改代码；new-api 一键包、Node 与 Cloudflare Worker 三种方式。 |
| [私密通道](channels.md) | 彼此通信的应用、智能体与服务 | 发布通道密钥，打开加密通道，选择中继或链本身作为承载。 |
| [群聊](groups.md) | 要加上至多 32 人群聊（实验性的格式 2 最多 128 人）的应用 | 建群并一次投递纪元消息与每份邀请，作为成员找到邀请，保存状态，照着排查清单解决常见问题。 |
| [MCP](mcp.md) | 使用 Claude、Cursor 或其他 MCP 客户端的任何人，以及 MCP 服务器作者 | 按网址添加公共服务的 MCP 工具；运行本地命令，它自己核验每个回答并钉住工具列表；或者 Tape out 你自己的 MCP 服务器。 |
| [AI 智能体](agents.md) | 为浏览器内智能体提供工具的任何人 | 把服务暴露为 WebMCP 工具，其回答始终经过签名检查。 |
| [常见问题与排障](faq.md) | 所有人 | 错误码、常见错误，以及读取器警告的含义。 |
| [升级到 1.0](upgrade-1.0.md) | 所有写过 0.x 代码的人 | 了解 1.0 承诺什么（稳定、实验性、内部）、相对 0.x 改了什么、该怎么写，以及完整的错误码表。 |

开始之前：Node.js 20 或更高版本，以及

```bash
git clone https://github.com/BruceLanLan/tapeapi.git && cd tapeapi && npm install
```

协议本身定义在 [`spec/`](../../../spec/)（TAP-20 至 TAP-27）中。凡是规则要紧之处，各指南都会链接到相应章节。
