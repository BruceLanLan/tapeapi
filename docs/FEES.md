# 费用模型 v0.3：无强制协议费 + 默认 1% 维护贡献（提供者可关闭）

> 2026-09-28 起取代 v0.2（"零协议费，贡献默认 0，建议 1%"）。变化在于贡献的**默认值**从 0 改为 1%，
> 并写成合约常量；运营方依然没有费率开关，消费者的价格依然不变。规范见 TAPI-22 §3.4。

**今天没有任何调用收费。** 付费调用用的托管合约还没有部署，要先通过独立审计才会部署。在那之前，所有线上方法都免费，
下面说的贡献一分钱也没有收过。

## 原则
1. **标准层永远免费。** 解析身份、读清单、验签、发现服务，不收费、不经过任何我们的服务器。
2. **没有强制协议费。** 托管合约没有运营方的费率开关，也不能暂停。协议本身不向消费者收取任何费用。
3. **默认 1% 维护贡献，提供者可以改成 0。** 付费调用通过 TapeAPI 托管合约结算时，默认从提供者应得的部分划出 1%
   给维护金库。消费者付的价格不变。每个提供者都可以为自己的服务把比例改成 0（关闭），或 0 到 50% 之间的任意值。
4. **默认值是合约常量，不是 owner 参数。** `DEFAULT_CONTRIBUTION_BPS = 100` 写死在合约里，部署后谁都改不了；
   上限 `MAX_CONTRIBUTION_BPS = 5000`（50%）同样是常量。owner 唯一的权力是更换金库（treasury）地址（以及两步转移 owner 本身）。
5. **关掉不受惩罚。** 比例为 0 的服务在合约、SDK、其他提供者那里得到完全相同的对待。目录站可以显示比例，
   但不能因此限制功能。
6. **贡献可见。** SDK 在解析服务时读出该服务的比例（`svc.contribution`），目录站也可以展示。

## 为什么默认开启是诚实的
- **改在任何人付费之前。** 托管合约没有部署，没有人付过一分钱，也没有人因为"默认 0"而接入后被改了规则。
  这是上线前的规则更新，不是事后加费。
- **消费者不受影响。** 贡献从提供者的所得里划出，消费者的价格一分不变。
- **提供者一笔交易就能关掉。** 电路持有人调用 `setContribution(circuits, tokenId, 0)` 即可，不需要任何人批准。
- **运营方拿不到开关。** 默认值是常量，owner 不能调高、不能改任何人的比例、不能暂停、不能动余额。
  如果将来想改默认值，只能部署一个新合约，旧合约照常运行。
- **为什么不是默认 0。** 规范维护、参考实现、审计、目录站运营需要一个稳定来源。默认 0 实际上等于没有来源；
  默认 1% 加上随时可关，是对维护者和提供者都说得清的折中。

## 具体规则（进合约）
- `setContribution(circuits, tokenId, bps)`：调用者必须是该电路当前持有人；provider = hub.accountOf(circuits, tokenId)；
  0 ≤ bps ≤ 5000。设过之后（包括设为 0），该值取代默认值。
- `contributionOf(provider)`：没设过时返回 100，设过则返回所设的值。
- `settle()`：先算出 `delta`，`contribution = delta * bps / 10000` 给 `treasury`，余下给 provider。bps 为 0 或金额取整为 0
  时不产生转账。
- `treasury` 由 owner 设置，改动发 `TreasuryChanged`。owner 没有其它权力。
- 别名登记：`ServiceDirectory` 可选要求 `DomainBinding.isContainerLive(container)` 为真。激活费 0.08 BNB/30 天付给协议，
  不付给我们。`labelFee` 保留为参数，默认 0。

**实现状态：** 仓库里的 v2 托管合约（`contracts/src/TapeAPIEscrow.sol`）早于本版，仍让每个提供者从 0 开始。
按本版实现默认值的是下一版托管，只有那一版会送审并部署。

## 金库
初期金库地址就是部署合约的钱包，部署时公开；换地址必须发 `TreasuryChanged` 事件。

## 结算代币（计划中，下一版托管）
计划支持 BNB Smart Chain 上的 BEM（主推）、BNB（由合约包装为 WBNB）、USDT、USDC、ETH、USD1。
这些都还没有写进规范，也还没有实现；TAPI-22 当前只规定 BEM。

## 我们的收入从哪来（不变）
自营服务按次收 BEM、托管控制台、帮企业铸电路开容器写清单的一站式服务。见 BUSINESS.md。维护贡献进金库，用于维护，公开报账。
TapeAPI 的点子来自 @Theairresearch，TapeAPI 所获任何收入的 10% 永久归其所有（见 BUSINESS.md 的分成承诺）。

## 可以作为"开关"的部分
比例就是开关，开关在每个提供者手里，不在我们手里。若将来社区希望有统一的协议费，正确路径是新的 TAP 加新的托管部署，
而不是给现有合约加后门。本次默认值的调整也走这条路径：它随下一版托管一起部署、一起审计。
