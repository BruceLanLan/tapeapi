# 最便宜拿到"电路 + 已激活容器"的方案（2026-09-20 链上实测，2026-09-30 更正费用）

目标：为 TapeAPI 拿到一个自己控制的电路 NFT 及其已激活容器，用作 TAP-20 的主网测试向量和 TapeAPI 自己的服务身份。

## 推荐路径：自建处理器（约 0.015 BNB ≈ 11 USD）
1. **创建处理器**：tapeout.net 首页「创建」→ 名字如 `TapeAPI`，晶体管供应量随意（≥前端要求的最小值），**铸造单价填 0**。付 0.001 BNB + gas。这两项上链后不可改。
2. **铸造晶体管**：在自己处理器详情页铸 2 到 10 个 NAND。单价 0，另付 0.0001 BNB 铸造协议费 + gas。
3. **流片一个最小电路**：画布上放 1 个 NAND（或一个 2 输入与门，2 个 NAND），Tape Out。付 0.0002 BNB 流片费 + gas，晶体管被销毁，得到电路 NFT `#1`。
4. **激活容器**：电路详情页「容器」→ 付 0.012 BNB 创建费。之后容器可写文件、可收发 TapeSend、可被 DeWebHub `_authorize` 通过（它要求 `NotOpened` 为假）。
5. **（可选）激活链上名字**：容器的链上名字 `<#1>.<处理器号>.tape` 自动可访问（HashPort 控制台，2026-09-26 核对）；只有将来要在 ServiceDirectory 登记别名时，才需要 `DomainBinding.bind("<#1>.<处理器号>.tape", 容器, 1)`（当前 `msg.value = 0`）让 `isContainerLive(容器)` 为真。免费层不需要。
6. **写入清单**：用 HashPort 控制台上传一个只含 `/.well-known/tapeapi.json` 的文件夹，或直接调 `SiteRegistry.putFile`。清单 ≤ 24,000 字节一笔交易写完，gas 约 0.001 BNB 量级。

合计：0.001（创建处理器）+ 0.0001（铸造协议费）+ 0.0002（流片费）+ 0.012（容器）+ gas（约 6 笔交易，BSC 每笔约 0.0003 BNB）≈ **0.015 BNB**（2026-09-30 按实测费用重算，结果不变）。

## 更省 0.001 BNB 的路径：借别人的 0 价处理器
跳过第 1 步，直接在一个铸造价为 0 且有供应的社区处理器上铸造（2026-09-30：402 个零价处理器里只剩 12 个还有供应，例如 `TapeOutTank` 0xC5F7…eA95 之类，选一个已有真实电路、名字不带诈骗字样的）。合计约 0.014 BNB。
不推荐的原因：服务身份挂在别人命名的处理器下，`<#ID>.<处理器号>.tape` 里处理器号是别人的；TapeAPI 作为标准提出方，自己的处理器更体面，而且"每个 API 一个电路、服务方自建处理器"正是我们要示范给企业看的路径。

## 注意事项
- 所有 TapeOut 合约均未在 BscScan 验证，费用以交易前钱包里显示的金额为准；前端说明也写了"发送前会用你的钱包再核对一次"。
- 处理器名字与铸造价创建后不可改；供应量太小进不了首页「在售」，但这对我们无所谓。
- 电路 NFT 转让 = 服务身份转让，钱包请用长期持有的地址，不要用热钱包。
- 完成后把处理器号、#ID、容器地址、清单 SHA-256 填进 TAP-20 §6.1 测试向量。
