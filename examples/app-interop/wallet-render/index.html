Experimental prototype. Not a TAP. Sends no transaction.

本页只用 window.ethereum 的三个方法：eth_requestAccounts（只取地址）、eth_chainId（只读链 ID）、eth_signTypedData_v4（签一份类型数据）。不查余额、不发交易、不切换网络、不联网请求任何东西。请只用新建的空钱包。名字 12.7.tape、13.7.tape 是示例，不是真实服务；签出的东西不会被任何服务接受。
This page calls three methods of window.ethereum only: eth_requestAccounts (the address), eth_chainId (read), eth_signTypedData_v4 (one typed-data signature). No balance, no transaction, no network switch, no network request. Use a new, empty wallet. 12.7.tape and 13.7.tape are example names, not real services; no service accepts what is signed here.

Purpose: see how a wallet shows this EIP-712 typed data — whether the first line (statement) is cut, how long strings and the string[] array are shown, whether the domain is shown in full, and any security warning. The signature is used for nothing.
